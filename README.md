## ✨ Ключевые особенности

* ⚡ **Сверхбыстрый Windows OCR:** Нативное чтение через системный WinRT API за **15–25 мс** без нагрузки на видеокарту.
* 🛸 **Автономный парящий мини-HUD:** Модульный открепляемый тулбар с ручкой `⋮⋮`, магнитной привязкой к 4 углам и защитой от улетания за экран.
* ⏸️ **Пауза (Alt + P):** Мгновенно скрывает окно перевода текста во время боя или катсцен, оставляя лишь компактный пульт, и моментально возобновляет чтение при снятии паузы.
* 🛡️ **Безопасен для античитов (Zero-Risk):** Работает чисто через оптическое распознавание (OCR). Не внедряется в память и файлы игры — риск бана исключен.
* 🧠 **Настоящий офлайн с локальными нейросетями:** Перевод работает прямо на вашем ПК через модели **Opus-MT** и **NLLB-200**. Никаких блокировок и обрывов.
* 🔄 **Умный гибридный режим (Graceful Fallback):** Переводите через Google/MyMemory онлайн, а при сбое сети программа сама переключится на локальную нейросеть.
* 💬 **Окно перевода в виде чата:** Реплики не исчезают, а аккуратно складываются в историю диалога с временными метками. Вы никогда не потеряете нить сюжета.
* 🪟 **Стильный оверлей и фокус на чтении:** Тёплая янтарная тема, селектор в стиле «Ножниц» Windows 11, адаптивный апскейл мелких шрифтов и фильтрация «печатающегося» текста.

> *p.s. На данном этапе поддерживается направление перевода **en $\rightarrow$ ru**. Мультиязычность и перевод с азиатских языков добавятся в версиях v0.5.1 и v0.6.0.*

## ⌨️ Горячие клавиши (по умолчанию)

| Сочетание | Действие |
| :--- | :--- |
| `Alt + Q` | Перевести выделенную область экрана |
| `Alt + W` | Включить / выключить авто-режим отслеживания области |
| `Alt + P` | ⏸️ Пауза / возобновление авто-режима (окно скрывается) |
| `Ctrl + ~` | Быстро скрыть / показать окно перевода |
| `Alt + C` | Экстренно остановить перевод и очистить очередь |
| `Alt + X` | Очистить историю диалога в окне |
| `Alt + G` | Включить / выключить сквозной клик сквозь окно в игру (*Ghost mode*) |

*(Все сочетания можно свободно переназначить в Настройках под вашу клавиатуру).*

## ⚠️ Особенности работы моделей:

* При использовании ультрабыстрого **Windows OCR** в авто-режиме рекомендуется использовать онлайн-переводчики (**Google / MyMemory**) либо быстрый локальный **Opus-MT** (~300 мс).
* Модель **NLLB-200** является тяжеловесной нейросетью (~2.5 ГБ) и выполняет генерацию на CPU за 1.5–3 секунды. Для комфортной игры с NLLB выставляйте ползунок «Задержка распознавания» в Настройках на 800–1200 мс.

3. Запустите **`ScreenTale.exe`**.
