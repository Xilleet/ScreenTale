## ⚡ v0.5.0 — Windows OCR Milestone

**Тема:** Переход на нативный системный OCR, ускорение в 15–20 раз и освобождение оперативной памяти, открепляемый тулбар с кнопками.  

### Задачи:
- [x] **[arch] Архитектура стратегий `ocr_engines.py`:**
  - Создание базового класса `OcrEngine` (`load`, `read`, `unload`, `is_available`) для бесшовного переключения между разными OCR-движками на лету.

- [x] **[feat] Нативный Windows OCR (WinRT API):**
  - Подключение системного OCR Windows 10/11 через WinRT API (`windows.media.ocr`).
  - Снижение задержки распознавания с ~500 мс до **10–25 мс** на кадр.
  - Нативное чтение без нагрузки на видеокарту (0 МБ VRAM).

- [x] **[feat] Проверка языковых пакетов ОС:**
  - Автоматическая проверка наличия нужного языкового пакета OCR в системе (`en-US`, `ja-JP` и др.).
  - Понятное предупреждение с инструкцией, если у пользователя не установлен нужный язык в Windows.

- [X] **[qol] ⏸️ Пауза авто-режима без сброса рамки (`Alt + P`):**
  - Возможность временно приостановить авто-сканирование (например, во время боя или анимаций в игре), сохранив выделенные координаты рамки.

- [X] **[add] Автономный парящий мини-HUD

*   **Тулбар теперь свободный:**

      - Панель управления больше не прибита намертво к окну перевода. Справа появилась удобная ручка **`⋮⋮`**, потянув за которую тулбар можно оторвать и утащить в любую точку экрана (хоть к миникарте игры, хоть на второй монитор).

      - Тулбар можно пристегнуть снаружи к любому из 4 углов окна перевода (*сверху-справа, снизу-справа, сверху-слева, снизу-слева*). Поднесите его к любому углу — и он "прищёлкнется" обратно.

      - Тулбар физически не может «провалиться» внутрь окна перевода и перекрыть текст или ресайз-грип. Если бросить его поверх текста — он сам мягко отскочит к ближайшему внешнему краю.

      - Тулбар и окно перевода теперь аппаратно ограничены границами рабочего стола. Они поддерживают мультимониторные связки (2–3 экрана), но ни при каких обстоятельствах не улетят в «чёрную пустоту» за пределы видимости.

## ✨ Ключевые особенности

* 🛡️ **Безопасен для античитов (Zero-Risk):** Работает чисто через оптическое распознавание (OCR). Не внедряется в память процессов и файлов игры — риск бана исключен.
* 🧠 **Настоящий офлайн с локальными нейросетями:** Перевод работает прямо на вашем ПК через модели **Opus-MT** и **NLLB-200**. Никаких блокировок и обрывов.
* 🔄 **Умный гибридный режим (Graceful Fallback):** Переводите через Google/MyMemory онлайн, а при сбое сети программа сама бесшовно переключится на локальную нейросеть.
* 💬 **Окно перевода в виде чата:** Реплики не исчезают, а аккуратно складываются в историю диалога с временными метками. Вы никогда не потеряете нить сюжета.
* 🪟 **Стильный оверлей и фокус на чтении:** Тёплая янтарная тема, селектор в стиле «Ножниц» Windows 11, адаптивный апскейл мелких шрифтов и фильтрация «печатающегося» текста.

p.s. На данном этапе есть только одностороння поддержка перевода ru->en, остальные языки (до 10 или более) добавится в версии 0.6

## ⌨️ Горячие клавиши (по умолчанию)

| Сочетание | Действие |
| :--- | :--- |
| `Alt + Q` | Перевести выделенную область экрана |
| `Alt + W` | Включить / выключить авто-режим отслеживания области |
| `Ctrl + ~` | Быстро скрыть / показать окно перевода |
| `Alt + C` | Экстренно остановить перевод в полёте и сбросить очередь |
| `Alt + X` | Очистить историю диалога в окне |
| `Alt + G` | Включить / выключить сквозной клик сквозь окно в игру (*Ghost mode*) |

*(Все сочетания можно свободно переназначить в Настройках под вашу клавиатуру).*

## Известные баги:

При совместной работе WinOCR и NLLB - происходит перегрузка очереди на перевод, из-за чего переводов вообще нет. Юзайте с WinOCR только Google/Mymemory/Opus.
