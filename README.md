## Ключевые особенности

* **In-Place AR-Оверлей (Бесшовное замещение текста):** Режим нативного перевода прямо поверх интерфейса игры или бабблов манги.
  * **Smart Tint:** Автоматический замер цвета фона по 4 точкам скрывает оригинальный английский/японский текст матовой подложкой в тон игре.
  * **Пространственный наклон (`atan2`):** Текст перевода поворачивается под тем же углом, что и оригинальные надписи в кадре.
  * **Автоподбор шрифта ($O(\log N)$):** Бинарный расчёт кегля под размер оригинального диалогового окна с вертикальным авто-ростом плашки.
  * **Индикатор «ИИ думает» (LookUpper-style):** При точечном клике прямо под курсором парит янтарная капсула с танцующими звёздами `✦ ✦ ✦`, плавно сменяясь переводом с упругой пружинной анимацией (*Spring Pop-In*). - *(еще в разработке)*
* **Локальный LLM-перевод (llama.cpp + GGUF):** Полноценные языковые модели прямо на вашей видеокарте или процессоре! Перевод художественного уровня, сохранение контекста сцены, сленга и характера персонажей без утечки данных в сеть.
* **Автоматический менеджер рантаймов:** Никакой ручной возни с C++ библиотеками. ScreenTale сам определяет железо (NVIDIA CUDA 12, Vulkan или CPU AVX2), скачивает официальные бинарники с GitHub и проводит скрытый Smoke Test перед запуском.
* **Каталог GGUF-моделей в 1 клик:** Встроенный загрузчик проверенных моделей прямо в Настройках (`Hy-MT2 1.8B`, `Qwen 2.5 7B`, `Sakura 4B Galgame`).
* **Сверхбыстрый нативный OCR:** Мгновенное чтение через системный **Windows OCR (WinRT API)** за **10–25 мс** с нулевой нагрузкой на видеокарту.
* **RapidOCR & Вертикальный текст (Tategaki):** Специализированный ONNX-движок для сложных стилизованных шрифтов и традиционных японских вертикальных столбцов (чтение сверху-вниз, справа-налево в манге и новеллах).
* **Автономный парящий мини-HUD:** Открепляемый пульт управления с ручкой `⋮⋮`, 4-сторонним магнитным докингом к углам экрана и защитой от перекрытия текста.
* **Управление в 1 клик мыши:** 
  * **СКМ (Колёсико):** Мгновенный точечный перевод фразы или кнопки под курсором.
  * **ПКМ:** Быстрое растворение активных плашек перевода с экрана.
* **100% безопасность для античитов (Zero-Risk):** Работает исключительно через сквозной системный слой (`HTTRANSPARENT`). Не внедряется в память процессов и DirectX/OpenGL — бан исключен.
* **Режим стримера (Anti-Loop):** Защита от захвата через `SetWindowDisplayAffinity` — плашки перевода видны только вам, но скрыты от записи OBS, Discord и скриншотеров (ShareX).

## ⌨Управление и горячие клавиши

| Сочетание / Клик | Действие |
| :--- | :--- |
| `Alt + Q` | **1-Click скан** окна игры (в режиме In-Place) / Перевод выделенной области |
| `Alt + W` | Включить / выключить авто-режим субтитров по рамке |
| `Клик СКМ (Колёсико)` | **Точечный перевод** фразы или кнопки под курсором мыши |
| `Клик ПКМ` | Мгновенно убрать активные плашки перевода с экрана |
| `Alt + P` | Пауза авто-режима (окно скрывается, тулбар остаётся) |
| `Ctrl + ~` | Быстро скрыть / показать окно перевода (в режиме Чата) |
| `Alt + C` | Экстренно остановить перевод и очистить очередь |
| `Alt + X` | Очистить историю диалогов |
| `Alt + G` | Включить / выключить сквозной клик в игру (*Ghost mode*) |

*(Все клавиатурные сочетания можно свободно переназначить в Настройках).*

## Установка и запуск

1. Скачайте архив **`ScreenTale_v0.7-beta.zip`** из раздела **[Releases](https://github.com/Xilleet/ScreenTale/releases)**.
2. Распакуйте архив в любую удобную папку.
3. Запустите **`ScreenTale.exe`**.
4. Выберите режим работы в левом сайдбаре:
   * `[ In-Place ]` — для нативного замещения диалогов прямо в игре.
   * `[ Чат ]` — для классического окна истории со скроллом.
5. Во вкладке **«Перевод»** настройте движок:
   * **Быстрый облачный:** Google Translate.
   * **Локальный ИИ:** Выберите **LLM**, нажмите «Установить движок» (программа сама подберет CUDA или Vulkan) и скачайте проверенную модель (например, `Hy-MT2 1.8B` или `Qwen 2.5 7B`).
