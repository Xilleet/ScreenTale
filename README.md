## ✨ Ключевые особенности

* 🛡️ **Безопасен для античитов (Zero-Risk):** Работает чисто через оптическое распознавание (OCR). Не внедряется в память процессов и файлов игры — риск бана исключен.
* 🧠 **Настоящий офлайн с локальными нейросетями:** Перевод работает прямо на вашем ПК через модели **Opus-MT** и **NLLB-200**. Никаких блокировок и обрывов.
* 🔄 **Умный гибридный режим (Graceful Fallback):** Переводите через Google/MyMemory онлайн, а при сбое сети программа сама бесшовно переключится на локальную нейросеть.
* 💬 **Окно перевода в виде чата:** Реплики не исчезают, а аккуратно складываются в историю диалога с временными метками. Вы никогда не потеряете нить сюжета.
* 🪟 **Стильный оверлей и фокус на чтении:** Тёплая янтарная тема, селектор в стиле «Ножниц» Windows 11, адаптивный апскейл мелких шрифтов и фильтрация «печатающегося» текста.

p.s. На данном этапе есть только одностороння поддержка перевода ru->en, остальные языки (до 10 или более) добавится в версии 0.6

## ⌨️ Горячие клавиши (по умолчанию)

| Сочетание | Действие |
| :--- | :--- |
| `Alt + Q` | Перевести выделенную область экрана |
| `Alt + W` | Включить / выключить авто-режим отслеживания области |
| `Ctrl + ~` | Быстро скрыть / показать окно перевода |
| `Alt + C` | Экстренно остановить перевод в полёте и сбросить очередь |
| `Alt + X` | Очистить историю диалога в окне |
| `Alt + G` | Включить / выключить сквозной клик сквозь окно в игру (*Ghost mode*) |

*(Все сочетания можно свободно переназначить в Настройках под вашу клавиатуру).*

   ```bash

2. Установите зависимости:
