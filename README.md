  <b>ScreenTale</b> — это легковесный экранный переводчик без рекламы и платных лимитов. 
  Создан геймером для геймеров, чтобы с комфортом читать сюжет в непереведенных визуальных новеллах, 
  JRPG, гачах и RPG-играх как через облачные сервисы, так и <b>полностью офлайн с мощью современных локальных нейросетей</b>.

## ✨ Ключевые особенности

* 🧠 **Локальный LLM-перевод (llama.cpp + GGUF):** Полноценные языковые модели прямо на вашей видеокарте или процессоре! Перевод художественного уровня, сохранение контекста сцены, сленга и характера персонажей без утечки данных в сеть.
* ⚡ **Автоматический менеджер рантаймов:** Больше никакой ручной возни с C++ библиотеками. ScreenTale сам определяет железо (NVIDIA CUDA 12, Vulkan или CPU AVX2), скачивает официальные бинарники с GitHub и проводит скрытый Smoke Test перед запуском.
* 📚 **Каталог GGUF-моделей в 1 клик:** Встроенный загрузчик проверенных моделей прямо в Настройках (`Hy-MT2 1.8B`, `Qwen 2.5 7B`, `Sakura 4B Galgame`).
* ⚡ **Сверхбыстрый нативный OCR:** Мгновенное чтение через системный **Windows OCR (WinRT API)** за **10–25 мс** с нулевой нагрузкой на видеокарту.
* 🌸 **RapidOCR & Вертикальный текст (Tategaki):** Специализированный ONNX-движок для сложных стилизованных шрифтов и традиционных японских вертикальных столбцов (чтение сверху-вниз, справа-налево в манге и новеллах).
* 🛸 **Автономный парящий мини-HUD:** Открепляемый пульт управления с ручкой `⋮⋮`, 4-сторонним магнитным докингом к углам экрана и защитой от перекрытия текста.
* ⏸️ **Умная пауза (`Alt + P`):** Мгновенно скрывает окно текста во время боя или катсцен, оставляя лишь компактный мини-HUD, и возобновляет перевод при снятии паузы.
* 👻 **Ghost Mode (`Alt + G`):** Сквозной клик сквозь окно перевода в игру без переключения окон (`HTTRANSPARENT`).
* 🛡️ **100% безопасность для античитов (Zero-Risk):** Работает исключительно через захват кадра и оптическое распознавание (OCR). Не внедряется в память процессов и DirectX/OpenGL — бан исключен.
* 🔄 **Бесшовный откат (Graceful Fallback):** Переводите через облако (Google / MyMemory), а при обрыве связи программа автоматически подхватит перевод офлайн-моделью.

## ⌨️ Горячие клавиши (по умолчанию)

| Сочетание | Действие |
| :--- | :--- |
| `Alt + Q` | Перевести выделенную область экрана |
| `Alt + W` | Включить / выключить авто-режим отслеживания области |
| `Alt + P` | Пауза авто-режима (окно скрывается, тулбар остаётся) |
| `Ctrl + ~` | Быстро скрыть / показать окно перевода |
| `Alt + C` | Экстренно остановить перевод и очистить очередь |
| `Alt + X` | Очистить историю диалога в окне |
| `Alt + G` | Включить / выключить сквозной клик в игру (*Ghost mode*) |

*(Все сочетания можно свободно переназначить в Настройках под вашу клавиатуру).*

## 📦 Установка и запуск

1. Скачайте архив **`ScreenTale_v0.6.1-beta.zip`** из раздела **[Releases](https://github.com/Xilleet/ScreenTale/releases)**.
2. Распакуйте архив в удобное место.
3. Запустите **`ScreenTale.exe`**.
4. В Настройках во вкладке **«Перевод»** выберите движок:
   * **Быстрый облачный:** Google Translate.
   * **Максимальный игровой:** выберите **LLM**, нажмите «Установить движок» (программа сама определит CUDA или Vulkan) и скачайте понравившуюся модель (например, `Hy-MT2 1.8B` или `Qwen 2.5 7B`).
